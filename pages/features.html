Pages Functions

Pages FunctionsはCloudflare Workersをベースにしたサーバーサイド処理機能です。 functions/ディレクトリにJavaScriptファイルを置くだけで、 対応するAPIエンドポイントがエッジで動作します。

🗺️
ファイルベースルーティング

functions/api/users.jsが/api/usersに対応。直感的なディレクトリ構造でAPIを構築。

⚡
エッジで実行

コールドスタートなし。ユーザーに最も近いエッジノードで即座に実行される。

🔗
ミドルウェア対応

_middleware.jsでリクエストを横断処理。認証チェック・ロギングなどを一元管理。

functions/api/users/[id].js — 動的ルート 
// /api/users/123 にアクセスすると id=123 が取得できる
export async function onRequestGet({ params, env }) {
  const { id } = params;

  // Cloudflare D1データベースから取得
  const user = await env.DB.prepare(
    'SELECT * FROM users WHERE id = ?'
  ).bind(id).first();

  if (!user) {
    return new Response('Not Found', { status: 404 });
  }

  return Response.json(user);
}

export async function onRequestPost({ request, env }) {
  const body = await request.json();
  // ユーザー作成処理...
  return Response.json({ success: true }, { status: 201 });
}
functions/_middleware.js — 認証ミドルウェア 
export async function onRequest({ request, next, env }) {
  // Authorizationヘッダーを確認
  const auth = request.headers.get('Authorization');

  if (!auth?.startsWith('Bearer ')) {
    return new Response('Unauthorized', { status: 401 });
  }

  // 認証OKなら次の処理へ
  return next();
}

Workersバインディング

Pages FunctionsからCloudflareの各種サービスへ透過的にアクセスできます。 追加の認証設定なしに、envオブジェクト経由で安全に利用できます。

Cloudflare Workers KV

エッジ分散型のKey-Valueストアです。セッション管理・設定値・キャッシュに最適です。

KVの使用例 
// wrangler.toml でバインディングを設定
[[kv_namespaces]]
binding = "MY_KV"
id = "abc123..."

// Pages Functionsから利用
export async function onRequest({ env }) {
  // 書き込み
  await env.MY_KV.put("key", "value", { expirationTtl: 3600 });

  // 読み取り
  const value = await env.MY_KV.get("key");
  return Response.json({ value });
}

Cloudflare D1

SQLiteをベースにしたサーバーレスデータベースです。標準SQLで使えます。

D1の使用例 
// wrangler.toml
[[d1_databases]]
binding = "DB"
database_name = "my-database"
database_id = "abc123..."

// SQLクエリを実行
export async function onRequest({ env }) {
  const { results } = await env.DB
    .prepare("SELECT * FROM posts ORDER BY created_at DESC LIMIT 10")
    .all();

  return Response.json(results);
}

Cloudflare R2

S3互換のオブジェクトストレージです。画像・動画・ファイルの保存に。

R2の使用例 
// ファイルをR2にアップロード
export async function onRequestPost({ request, env }) {
  const formData = await request.formData();
  const file = formData.get('file');

  await env.MY_BUCKET.put(
    file.name,
    file.stream(),
    { httpMetadata: { contentType: file.type } }
  );

  return Response.json({ success: true });
}

Cloudflare Workers AI

エッジで動作するAI推論エンジンです。LLM・画像生成・翻訳などが利用可能です。

Workers AIの使用例 
// エッジでLLM推論を実行
export async function onRequestPost({ request, env }) {
  const { prompt } = await request.json();

  const response = await env.AI.run(
    '@cf/meta/llama-3-8b-instruct',
    { messages: [{ role: 'user', content: prompt }] }
  );

  return Response.json(response);
}

Web Analytics

Cloudflare Web Analyticsはプライバシー重視のアクセス解析ツールです。 Cookieを使用せず、IPアドレスも収集しないため、GDPRやCCPAに準拠しやすい設計です。

🔒
Cookieフリー

Cookieバナーが不要。GDPRに配慮したプライバシーファーストな計測。

📊
Core Web Vitals

LCP・FID・CLSなどのCore Web Vitalsを実際のユーザーデータで計測。SEO改善に活用可能。

🆓
無料で利用可能

Cloudflare Pagesで公開したサイトには追加費用なしでWeb Analyticsが使えます。

セキュリティ機能

Cloudflare Pagesはインフラレベルのセキュリティ機能を標準で搭載しています。

🛡️
DDoS保護

Cloudflareの大容量ネットワーク（209 Tbps以上）によるDDoS攻撃の自動緩和。設定不要で有効。

🔐
自動SSL/TLS

カスタムドメインに対してLet's Encrypt証明書を自動発行・更新。更新忘れによるHTTPS切れがなくなる。

🤖
ボット管理

悪意あるボットのスクレイピング・クローリングをCloudflareのAI判定で自動ブロック。

🌍
Geo制限

特定の国・地域からのアクセスを制限したり、地域ごとに異なるコンテンツを配信できる。

Cloudflare Access（アクセス制限）

Cloudflare Accessを使うと、特定のユーザー・グループのみがサイトにアクセスできるよう制限できます。 社内向けサイトや、ステージング環境の保護に最適です。

🔑 Accessで使える認証方法

Google Workspace / Microsoft 365 / GitHub / Okta / OneLogin / SAML 2.0 など主要なIdPに対応。 ワンタイムパスコード（メール認証）も使えるため、既存のIdPがなくてもすぐに導入できます。

1

Cloudflare Zero Trustダッシュボードを開く

Cloudflareダッシュボード → Zero Trust → Access → Applicationsに移動します。

2

アプリケーションを作成

「Add an application」→「Self-hosted」を選択し、保護するドメイン（例: preview.example.com）を設定します。

3

アクセスポリシーを設定

誰がアクセスできるかのルールを定義します。例：「メールドメインが @company.com のユーザーのみ許可」

画像最適化

CloudflareのImage Resizing機能をPages Functionsと組み合わせると、 オンザフライで画像のリサイズ・フォーマット変換ができます。

functions/images/[...path].js 
// /images/photo.jpg?w=800&f=webp のリクエストを処理
export async function onRequest({ request, params }) {
  const url = new URL(request.url);
  const width  = url.searchParams.get('w') || 1200;
  const format = url.searchParams.get('f') || 'webp';

  const imageUrl = `https://assets.example.com/${params.path}`;

  return fetch(imageUrl, {
    cf: {
      image: {
        width:  Number(width),
        format: format,      // webp, avif, jpeg, png
        quality: 85,
        fit: 'scale-down'
      }
    }
  });
}
