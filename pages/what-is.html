サービス概要

Cloudflare Pagesは、Cloudflare社が提供する静的サイト・フルスタックWebアプリケーション向けの ホスティングプラットフォームです。2021年4月に正式リリースされ、現在では世界中の開発者・企業に 利用されています。

特徴は「GitリポジトリとCloudflareを繋ぐだけ」というシンプルさにあります。 GitHubやGitLabにコードをpushすると、Cloudflareが自動的にビルドを実行し、 世界300箇所以上のエッジロケーションに配信します。

💡 静的サイト vs 動的サイト

静的サイトとは、HTMLやCSS、JavaScriptなどのファイルをそのまま配信するサイトです。 React・Vue・Nuxtなどのフレームワークを使ったSPAや、Astro・Hugo・Jekyll等の 静的サイトジェネレーター(SSG)で生成したサイトが対象です。 Pages Functionsを使えば動的な処理（API・認証等）も追加できます。

🌐
エッジ配信

世界300+ロケーションから最寄りのエッジノードで自動配信

🔄
CI/CD統合

Git pushで自動ビルド&デプロイ。PRごとにプレビューURL生成

⚡
Functions内蔵

Pages Functionsでサーバーレス処理もエッジで実行可能

誕生の背景

Cloudflare Pagesが登場する以前、静的サイトホスティングといえばNetlify・Vercel・GitHub Pagesが 主流でした。しかしCloudflareはすでに世界最大規模のCDNインフラを持っており、 そのネットワークを活かしたホスティングサービスは自然な進化でした。

2021

Cloudflare Pages ベータ公開

2021年3月にベータ版を公開。GitHub連携、自動ビルド、無制限帯域という特徴でたちまち注目を集める。

GA

一般提供(GA)開始・Pages Functions発表

正式リリースと同時にサーバーレス関数「Pages Functions」を発表。静的サイト以上の可能性が広がる。

2022

GitLab連携・Analytics追加

GitHubに加えGitLabもサポート。Web Analyticsが統合され、プライバシー配慮型の分析が可能に。

2023

Workers・KV・D1との深い統合

Pages FunctionsからCloudflare Workers KV、D1データベース、R2オブジェクトストレージを透過的に利用可能に。

アーキテクチャ

Cloudflare Pagesは大きく3つのレイヤーで構成されています。

ビルドパイプライン 
# Gitへのpushをトリガーにビルドが自動実行
git push origin main
   ↓
1. Webhookを受信  # GitHub/GitLabからCloudflareへ通知
2. ソースコードをクローン
3. フレームワークを自動検出  # React, Vue, Nuxt, Astro...
4. npm install && npm run build
5. 成果物をエッジに配信
   ↓
https://[project].pages.dev  # デプロイ完了！

ビルドはCloudflareが管理するコンテナ環境で実行されます。Node.js、Python、Go等のランタイムに対応しており、環境変数を安全に渡すことも可能です。

ビルド済みの静的ファイルはCloudflareのグローバルネットワーク全体に複製されます。ユーザーがアクセスすると、地理的に最も近いエッジノードから応答が返ります。

  • 世界300以上のエッジロケーションに自動レプリケーション
  • HTTP/3 (QUIC)・Brotli圧縮・Early Hintsに対応
  • スマートキャッシング戦略でキャッシュヒット率を最大化
  • カスタムドメインには自動的にSSL/TLS証明書を発行

Pages Functionsにより、静的サイトにサーバーサイド処理を追加できます。

functions/api/hello.js 
export async function onRequest(context) {
  const { request, env } = context;
  return new Response(
    JSON.stringify({ message: "Hello from the Edge!" }),
    { headers: { 'Content-Type': 'application/json' } }
  );
}

このファイルをfunctions/api/hello.jsに置くだけで、/api/helloエンドポイントがエッジで動作します。

他サービスとの比較

主要な静的サイトホスティングサービスとの機能・制限を比較します。

比較項目 ☁️ CF Pages ▲ Vercel ◆ Netlify 🐙 GitHub Pages
無料プラン帯域制限 無制限 100GB/月 100GB/月 100GB/月
無料プランビルド 500回/月 100回/日 300分/月 10回/時
カスタムドメイン(無料) ✓ ✓ ✓ ✓
サーバーレス関数(無料) ✓ Functions △ 制限あり △ 制限あり ✗
PRプレビュー ✓ 無制限 ✓ ✓ ✗
DDoS保護 ✓ 標準 △ 別途 △ 別途 ✗
グローバルCDN拠点数 300以上 ~70 ~100 ~30
GitLab対応 ✓ ✗ ✓ ✗
✅ Cloudflare Pagesが特に優れている点

帯域制限が無制限である点は他サービスにはない大きな強みです。 高トラフィックなサイトでも追加料金を気にせず運用できます。 また300以上のエッジロケーション数はVercel・Netlifyを大幅に上回ります。

ユースケース

Cloudflare Pagesはどのようなプロジェクトに最適でしょうか？

📝
ブログ・ドキュメントサイト

Astro・Hugo・Jekyll等のSSGと組み合わせて高速なブログやドキュメントサイトを構築。

🛒
ECサイト

Next.js・NuxtのSSG/ISRモードで商品ページを静的生成し、超高速なショッピング体験を提供。

💼
企業サイト・LP

マーケティングサイトやランディングページをスピーディーに公開。DDoS保護も標準装備。

⚛️
SPAアプリケーション

React・Vueで構築したSPAをデプロイ。Pages Functionsでバックエンドも同一リポジトリで管理。

よくある質問

Cloudflare PagesはPHPのような動的なサーバーサイド処理には対応していません。 WordPressをそのまま動かすことはできませんが、 WordPressをヘッドレスCMSとして使い、フロントエンドのみをPagesにデプロイするという 構成（Headless WordPress）は多く採用されています。
Pages Functions（エッジ上のサーバーレス関数）から Cloudflare D1（SQLiteベースのデータベース）やCloudflare KV（Key-Valueストア）を 利用できます。外部のSupabase・PlanetScaleなどのデータベースへの接続も可能です。
はい、無料プランでも帯域無制限でカスタムドメイン対応のため、 多くのプロジェクトで本番環境として利用可能です。 高度な認証アクセス制限（Cloudflare Access）や追加ビルド枠が必要な場合にProプランを検討しましょう。
Pages FunctionsはCloudflare Workersをベースにしているため、 Next.js・Nuxt・SvelteKitなどフレームワークのSSRモードを エッジで実行できます（Edge Runtime対応が必要）。 ただしNode.js専用のAPIは一部使用できないため、フレームワークのドキュメントを確認してください。
